# Contributing

Thanks for considering a contribution.

## Before submitting

1. Open an issue to describe substantial changes or bug fixes before starting work.
2. Keep changes focused and include or update unit tests when behavior changes.
3. Install development dependencies with `python -m pip install -e ".[dev]"`.
4. Run `ruff check .` and `python -m unittest discover -s tests -v`.
5. Open a pull request with a clear description of the change and any device-specific testing.

Please do not commit account data, downloaded media, credentials, or local environment files.
