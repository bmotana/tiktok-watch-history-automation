# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Contact the repository maintainer privately through the contact options on the GitHub profile [@bmotana](https://github.com/bmotana), and include steps to reproduce and any relevant impact. Please allow time for a fix before publicly disclosing the issue.

This project is maintained on a best-effort basis; there is no guaranteed response time or supported-version schedule.
